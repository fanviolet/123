# Art direction

- Original casual 3D, not a clone of Stack Ball or Talking Tom.
- Stack Ball reference principles: vibrant contrast, clean silhouettes, immediate readability and impactful feedback.
- Talking Tom reference principles: friendly rounded mascot, toy-like environment, glossy but soft material response.
- Original mascot: **Blox**, a rounded yellow/blue helper robot.
- Palette: cyan sky, warm yellow, coral, mint, violet, sky blue.
- Mobile target: simple PBR materials, low-poly compound meshes, Godot GL Compatibility renderer and MSAA 2x.
- Gameplay objects are everyday stackable forms with distinct silhouettes so the next placement can be read immediately on a phone screen.
