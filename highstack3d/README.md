# HighStack 3D — Native 3D Mobile Build

This project is a native Godot 4.7.2 3D rebuild of the HighStack concept. It is not the previous WebView/2D prototype.

## Visual direction
Original bright, toy-like casual 3D art: saturated colors, soft/glossy material response, readable silhouettes, friendly mascot, clean portrait UI. It references genre-level visual principles seen in casual titles without copying proprietary characters, meshes, textures, UI, names, or branded assets.

## Included
- 12 original GLB models generated specifically for the project.
- Physics-based 3D stacking on a fixed footprint.
- Eight everyday block types.
- Height score, coins, Perfect combo, camera climb.
- Casual / Ranked split.
- Stabilizer, Safety, Undo rescue systems.
- Persistent progression, skills, shop/rank surfaces.
- Rewarded revive / rewarded coin / interstitial test adapters.
- Simulated rivals explicitly labelled `Rival`.
- Android portrait configuration.

## Production-bound integrations
AdMob, Google Play Billing and Google Play Games require publisher-owned IDs, OAuth/configuration and Play Console products. The debug/test build uses safe simulated adapters. See `Documentation/PRODUCTION.md`.
